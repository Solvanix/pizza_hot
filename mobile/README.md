# Pizza Hot Mobile

تطبيق Expo/React Native لعميل Pizza Hot — بلعين. يحتوي الإصدار الأول على:

- صفحة رئيسية عربية موجهة للطلب.
- منيو بفئات وأحجام وأسعار.
- سلة محفوظة محليًا مع تعديل وحذف وإجمالي.
- إرسال الطلب إلى واتساب مع ملخص الطلب.
- برنامج نقاط: 50 نقطة ترحيبية، عرض الرصيد والمكافآت واستبدالها.
- تنقل سفلي مناسب للهاتف ودعم Expo Web.

## التشغيل

```bash
cd mobile
pnpm install
pnpm start
```

ثم افتح التطبيق عبر Expo Go أو شغّل `pnpm web` لمعاينة الواجهة على الويب.

## حدود الإصدار الأول

هذا الإصدار MVP ويستخدم `AsyncStorage` للسلة والولاء، لذلك لا يُعد مصدرًا آمنًا لرصيد النقاط ولا يسجل الطلبات على خادم. قبل الإطلاق التجاري يجب إضافة API وقاعدة بيانات لتسجيل العملاء والطلبات، إضافة النقاط بعد التسليم فقط، التحقق من الهاتف، وإرسال Push Notifications. كذلك يجب نقل حالة الطلب وبيانات الولاء من التخزين المحلي إلى الخادم.
